DocumenterDocstringStyle.jl

A Documenter.jl plugin that checks function docstrings against a fixed Markdown schema and renders them in a structured layout. One plain Markdown source can look like the PyTorch, NumPy, mkdocstrings or docs.rs docs, and still read well in the REPL.

makedocs(; modules = [MyPkg], plugins = [SchemaConfig(theme = :pydata)])
